First public release.

**Download `Seek-0.1.0.zip` below**, unzip it, and drag `Seek.app` to Applications. It runs on Apple silicon and Intel Macs with macOS 14 or later.

### First launch
Seek isn't notarized by Apple yet, so macOS blocks it the first time:
1. Open `Seek.app`; macOS says it can't verify it. Click **Done**.
2. Go to **System Settings → Privacy & Security**, scroll down, and click **Open Anyway** next to Seek.
3. Allow access to Desktop, Documents and Downloads when asked.
4. Press **⌥ Space** to search.

### What's in it
- Instant name search with its own index, kept live by FSEvents. Exact names always rank first.
- Full-text search (SQLite FTS5, BM25) across code, PDF, Word, PowerPoint and Excel files.
- OCR on screenshots and photos with Apple Vision.
- Semantic search with the potion-base-8M embedding model, bundled in the app.
- An evidence pane showing where each file matched, a home screen, and `changed:` date filters.

`SHA256SUMS` lets you verify the download: `shasum -a 256 -c SHA256SUMS`.
